# Trenér obhajoby

Mobilní appka na učení k obhajobě: celá práce v kostce, kartičky s pojmy, zkoušení otázek komise, scénář po slajdech a plán učení. Funguje i offline.

## Jak to dát na GitHub Pages

1. Na github.com vytvoř nový repozitář, třeba `obhajoba` (může být Public).
2. Klikni **Add file → Upload files** a přetáhni všechny soubory z téhle složky (index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png). Ulož **Commit changes**.
3. Jdi do **Settings → Pages**. U *Source* vyber **Deploy from a branch**, branch **main**, složka **/ (root)**, **Save**.
4. Za minutu bude appka na `https://TVOJE-JMENO.github.io/obhajoba/`.
5. Na mobilu otevři odkaz a dej **Přidat na plochu** (Safari: Sdílet → Přidat na plochu, Chrome: ⋮ → Přidat na plochu).

Postup (odškrtnuté úkoly, „umím“) se ukládá jen v telefonu, ve kterém appku používáš.

Pozor: repozitář typu Public uvidí kdokoli s odkazem, včetně tržeb pekárny. Jestli to nechceš, zvaž private repozitář (Pages u private repa vyžaduje placený GitHub) nebo odkaz nikomu nedávej.
